## 🚀 Executando o Projeto

Siga as instruções abaixo para rodar o projeto no seu ambiente local:

1. **Clone o repositório:**
   ```bash
   git clone git@github.com:function404/myprofile_.git
   ```

2. **Navegue até o diretório:**
   ```bash
   cd myprofile_
   ```

3. **Instale as dependências:**
   ```bash
   npm install
   ```

4. **Configuração de Ambiente (.env.local):**
   Crie um arquivo `.env.local` na raiz do projeto com as seguintes chaves:
   ```env
   # Supabase Keys
   NEXT_PUBLIC_SUPABASE_URL=sua_url_aqui
   NEXT_PUBLIC_SUPABASE_ANON_KEY=sua_anon_key_aqui

   # EmailJS Keys (Para envio de formulário de contato)
   NEXT_PUBLIC_SERVICE_ID=seu_service_id
   NEXT_PUBLIC_TEMPLATE_ID=seu_template_id
   NEXT_PUBLIC_USER_ID=seu_user_id
   ```

5. **Execute o servidor local:**
   ```bash
   npm run dev
   ```

6. **Acesse a aplicação:**
   Abra `http://localhost:3000` no seu navegador.
